# 카드 디자인 공용 프롬프트 — hero 초안 v0 (외부 이미지 AI용, 2026-07-27)

> hero: 카드 디자인은 별도 AI 에서 뽑는다. 어디서든 세션 시작 시 레퍼런스 이미지와 함께 전달할 **공용 프롬프트 양식**.
> 이 초안을 **받는 입장(우리 에셋 파이프라인)** 기준으로 수정하는 것이 과제. 아래는 초안 원문 그대로.

---

첨부한 레퍼런스 이미지를 이번 작업의 시각적 규격 참고 자료로 사용해 주세요.

레퍼런스의 기존 캐릭터나 이름을 복제하는 것이 아니라, 다음 요소만 고정 기준으로 사용합니다.

- 가로형 캐릭터 카드 시트 구성
- 세로형 카드의 종횡비
- 카드 크기와 간격
- 캐릭터 픽셀 아트 밀도
- 카드 프레임의 정보 구조
- 전신 캐릭터와 경기용 얼굴 아이콘의 연결 방식

이번 세션에서 별도로 전달할 테마에 맞춰 새로운 캐릭터들을 제작해 주세요.

# 1. 작업의 고정 요소와 가변 요소

고정 요소:
- 카드 시트의 전체 비율
- 카드의 세로 비율
- 카드 크기와 정렬
- 캐릭터가 카드 안에서 차지하는 크기
- 픽셀 아트의 표현 밀도
- 경기용 원형 픽셀 아이콘 규격

가변 요소:
- 국가
- 시대
- 신화
- 전설
- 실제 인물 모티프
- 종족
- 의상
- 축구 포지션
- 캐릭터의 능력과 연출

레퍼런스의 캐릭터 내용은 고정하지 않습니다.
이번 세션에서 전달하는 새로운 테마를 우선 적용합니다.

# 2. 전체 결과물 규격

결과물은 가로형 캐릭터 카드 시트 한 장으로 제작합니다.

기본 구성:
- 상단: 제목과 포지션 범례
- 중앙: 캐릭터 카드 그리드
- 하단: 해당 캐릭터들의 경기용 픽셀 아이콘 예시

기본 카드 수가 12장이라면:
- 6열 × 2행
- 모든 카드의 크기 동일
- 모든 카드의 세로 비율 동일
- 카드 사이의 간격 동일
- 카드의 상단과 하단 정렬선 동일

카드 수가 달라지더라도 빈 공간 없이 균형 있게 정렬합니다.

게임 경기장, 전술판, 상점, 덱 설정 화면 등 별도의 게임 UI는 만들지 않습니다.
오직 캐릭터 카드 시트와 경기용 아이콘 예시만 출력합니다.

# 3. 카드 비율과 내부 구도

모든 카드는 동일한 세로형 비율을 사용합니다.

권장 카드 비율:
- 가로 1 : 세로 1.65~1.75
- 레퍼런스 이미지와 유사한 길고 좁은 세로 카드

모든 카드에서 캐릭터 크기를 통일합니다.

캐릭터 배치:
- 머리는 카드 상단에서 약 12~18% 아래에 위치
- 발은 카드 일러스트 영역 하단에서 약 5~10% 위에 위치
- 캐릭터 전신이 잘리지 않게 배치
- 캐릭터 높이는 일러스트 영역의 약 70~80%
- 캐릭터마다 카메라 거리와 비율을 크게 바꾸지 않음
- 거대한 캐릭터도 다른 카드와 비슷한 시각적 부피로 조정
- 작은 캐릭터도 지나치게 작게 표현하지 않음

카드 내부 구조:
- 상단: FW, MF, DF, GK 등의 포지션 표시
- 중앙: 전신 또는 거의 전신 캐릭터 일러스트
- 하단: 이름, 이명, 희귀도 또는 간단한 역할 영역
- 가장 아래: 짧은 설명이나 속성 아이콘을 위한 영역

카드마다 정보 배치 구조는 동일하게 유지합니다.

# 4. 픽셀 아트 스타일

전체 스타일은 고해상도 픽셀 아트입니다.

- 픽셀의 모서리가 선명해야 함
- 부드러운 디지털 페인팅처럼 표현하지 않음
- 지나치게 작은 노이즈 픽셀을 남발하지 않음
- 캐릭터 실루엣이 배경과 명확하게 구분되어야 함
- 얼굴, 머리 형태, 의상, 자세가 카드마다 구별되어야 함
- 축구공과 축구 동작이 명확하게 보여야 함

카드 일러스트에서는 비교적 세밀한 픽셀 표현을 사용해도 됩니다.
다만 얼굴과 신체 비율은 모든 카드에서 같은 스타일로 유지합니다.

# 5. 축구 캐릭터 표현

모든 캐릭터는 판타지 인물이나 역사적 인물이기 전에 축구선수로 보여야 합니다.

반드시 포함할 요소:
- 축구 유니폼 또는 축구 유니폼으로 재해석한 의상
- 축구화
- 축구공
- 패스, 드리블, 슈팅, 태클, 세이브 중 하나의 축구 동작
- 포지션을 연상시킬 수 있는 자세

판타지, 신화, 역사, 실제 인물 모티프는 다음 요소를 통해 표현합니다.

- 머리 실루엣
- 표정
- 피부색
- 수염
- 헤어스타일
- 종족 특징
- 유니폼 문양
- 색상
- 제한된 장식
- 캐릭터 주변의 속성 효과

무기나 갑옷이 축구공과 축구 동작보다 중요하게 보이면 안 됩니다.
캐릭터는 전사가 아니라 축구선수로 읽혀야 합니다.

# 6. 캐릭터별 식별 요소

각 캐릭터는 다음 항목 중 최소 3개 이상으로 구분합니다.

- 머리 외곽 실루엣
- 헤어스타일
- 헤어 컬러
- 피부색
- 눈매
- 눈동자 색
- 수염
- 귀, 뿔, 왕관, 모자 등의 머리 장식
- 얼굴 문양
- 유니폼 주조색
- 유니폼 보조색
- 포지션에 맞는 자세
- 대표 속성 효과

같은 시트 안에서 서로 비슷한 머리와 얼굴을 반복하지 않습니다.

# 7. 경기용 픽셀 아이콘 제작 규격

각 카드 캐릭터마다 실제 경기 화면에 사용할 얼굴 중심 픽셀 아이콘을 함께 제작합니다.

게임 화면 전체는 만들지 않습니다.
시트 하단에 캐릭터별 아이콘 샘플만 일렬로 보여줍니다.

아이콘은 카드 일러스트와 별개의 캐릭터가 아니라,
동일한 캐릭터를 단순화한 파생 이미지여야 합니다.

## 아이콘 논리 해상도

기본 경기용 얼굴 스프라이트:
- 논리 해상도 16×16px
- 시트에서는 확인할 수 있도록 최근접 보간 방식으로 크게 확대하여 표시
- 픽셀을 흐리게 확대하지 않음
- 안티앨리어싱 사용 금지
- 픽셀 경계가 선명해야 함

필요하다면 보조 원본으로 32×32px 얼굴 아이콘을 함께 설계할 수 있지만,
최종 경기용 기준은 16×16px입니다.

## 16×16 얼굴 스프라이트 내부 구성

- 얼굴과 머리 중심
- 가슴 아래 신체는 표현하지 않음
- 어깨는 최대 1~2픽셀 정도만 허용
- 머리와 얼굴이 캔버스의 약 75~85%를 차지
- 상단, 좌우에 최소 1픽셀의 안전 여백 유지
- 얼굴은 정면 또는 약한 3/4 방향
- 캐릭터마다 시선 방향을 제각각 바꾸지 않음
- 모든 캐릭터의 얼굴 크기를 동일하게 맞춤

아이콘 안에서 우선 보존할 요소:
1. 머리 실루엣
2. 헤어 또는 머리 장식
3. 얼굴과 피부색
4. 눈매
5. 수염
6. 대표 색상
7. 작은 종족 특징

아이콘에서 제거할 요소:
- 복잡한 배경
- 축구공
- 전신
- 긴 무기
- 큰 날개 전체
- 오라
- 마법진
- 파티클
- 카드 프레임 장식
- 작은 액세서리
- 읽을 수 없는 미세 문양

날개, 뿔, 왕관, 동물 귀 등 중요한 특징은
16×16에서도 알아볼 수 있도록 단순한 실루엣으로 축약합니다.

## 아이콘 색상 규칙

16×16 아이콘 하나에 사용하는 색상은 가급적 다음 수준으로 제한합니다.

- 피부색: 1~2색
- 머리색: 2~3색
- 눈 또는 얼굴 포인트: 1색
- 대표 장식색: 1~2색
- 외곽선: 1색

전체적으로 약 6~10색 안에서 표현합니다.

카드의 모든 색을 축소해 넣지 않습니다.
캐릭터를 대표하는 핵심 색상만 남깁니다.

# 8. 원형 경기 토큰 규격

16×16 얼굴 스프라이트를 게임에서는 원형 토큰 안에 넣습니다.

권장 논리 크기:
- 전체 원형 토큰: 24×24px
- 내부 얼굴 스프라이트: 16×16px
- 얼굴 주변 내부 여백: 약 2px
- 팀 컬러 외곽 링: 약 2px
- 바깥쪽 투명 안전 여백: 약 1px

원형 토큰의 구성:
- 중앙: 캐릭터 얼굴
- 내부 배경: 어두운 네이비 또는 매우 어두운 무채색
- 외곽 링: 팀 컬러
- 외부 장식: 최소화

팀 구분:
- 우리 팀: 선명한 블루 링
- 상대 팀: 선명한 레드 링
- 중립 또는 미지정: 회색 링
- 선택된 선수: 기존 팀 링 바깥에 얇은 금색 또는 흰색 링 추가
- 공 소유 선수: 토큰 하단에 작은 공 마커 또는 점 표시

팀 컬러는 외곽 링에만 적용합니다.
캐릭터 얼굴이나 머리색을 팀 컬러로 변경하지 않습니다.

캐릭터의 속성, 국가, 희귀도에 따라 원형 링 색상을 바꾸지 않습니다.
링은 오직 팀을 구분하는 용도입니다.

# 9. 아이콘의 통일성과 가독성

모든 경기 아이콘은 한 세트처럼 보여야 합니다.

통일할 항목:
- 얼굴 크기
- 눈의 높이
- 머리 중심 위치
- 외곽선 두께
- 빛의 방향
- 명암 단계
- 배경색
- 원형 링 두께
- 원 안의 여백

멀리서 보았을 때는 팀 컬러 링이 가장 먼저 보여야 합니다.
가까이 보았을 때는 머리 실루엣과 대표 색상으로 캐릭터를 구별할 수 있어야 합니다.

아이콘을 카드 일러스트처럼 화려하게 만들지 않습니다.
카드는 수집성과 캐릭터성을 보여주고,
경기 아이콘은 위치와 상태를 빠르게 확인하는 용도입니다.

# 10. 시트 하단 아이콘 샘플 표시

카드 그리드 아래에 모든 캐릭터의 경기용 아이콘을 카드 순서와 동일하게 배치합니다.

각 캐릭터마다 다음 두 가지를 보여줍니다.

- 16×16 얼굴 스프라이트 확대본
- 블루팀 링이 적용된 원형 토큰

공간이 충분하다면 대표 캐릭터 2~3명에 한해 다음 상태도 함께 보여줍니다.

- 블루팀 기본 상태
- 레드팀 기본 상태
- 선택된 상태
- 공 소유 상태

하지만 게임 경기장 전체 화면은 출력하지 않습니다.

# 11. 포지션 규칙

포지션 표기는 다음 약어를 사용합니다.

- FW: 공격수
- MF: 미드필더
- DF: 수비수
- GK: 골키퍼

포지션 색상은 전체 시트에서 통일합니다.

- FW: 레드 또는 오렌지 계열
- MF: 그린 계열
- DF: 블루 계열
- GK: 골드 또는 옐로 계열

이 포지션 색상은 카드의 작은 포지션 표시와 분류에만 사용합니다.
경기용 원형 토큰의 외곽 링에는 포지션 색상을 사용하지 않습니다.

# 12. 출력 전 확인사항

결과물을 만들기 전에 다음을 반드시 확인합니다.

- 모든 카드의 가로와 세로 크기가 동일한가
- 모든 캐릭터의 전신 크기가 유사한가
- 카드마다 카메라 거리가 일정한가
- 카드가 잘리거나 프레임 밖으로 나가지 않았는가
- 카드 순서와 하단 아이콘 순서가 같은가
- 모든 아이콘의 얼굴 크기가 같은가
- 16×16에서도 핵심 실루엣이 남아 있는가
- 원형 토큰 링이 캐릭터 속성이 아니라 팀을 나타내는가
- 게임 화면이나 불필요한 UI가 포함되지 않았는가
- 이번 세션에서 전달한 테마가 정확히 반영되었는가

이번 작업의 최우선 목표는 다음 두 가지입니다.

1. 모든 캐릭터 카드가 동일한 규격과 비율로 보이는 것
2. 카드 캐릭터가 일관된 16×16 경기용 얼굴 아이콘으로 변환되는 것

이제 다음 메시지에서 전달할 테마와 캐릭터 조건을 적용해
동일한 카드 시트 규격으로 제작해 주세요.
