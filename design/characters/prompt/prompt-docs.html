ChatGPT·Gemini 등 대화형 이미지 AI 용. 어기면 산출이 실제로 깨지는 규칙만 남겼다. 레퍼런스와 함께 붙여넣고, 테마는 다음 메시지로 준다.

1,182자 · 레퍼런스 이미지와 함께 붙여넣는다

픽셀 아트 축구 캐릭터 원화를 만듭니다. 첨부한 레퍼런스는 그림 스타일만 참고하고, 거기 보이는 카드 테두리·이름표·별·원형 토큰은 그리지 마세요(게임이 따로 합성합니다).

금지 — 하나라도 있으면 에셋으로 못 씁니다

  • 배경. 완전 투명 PNG 로 주세요. 불가능하면 순수 마젠타 #FF00FF 단색(안티앨리어싱 없이).
  • 글자 일체 — 이름·이명·희귀도·포지션·능력치·설명·서명.
  • 카드 프레임·테두리·배경 패널, 원형 토큰·팀 컬러 링·등번호 뱃지.
  • 바닥 그림자·외곽 글로우·오라·파티클.

스타일

  • 픽셀 아트. 픽셀 모서리 선명, 안티앨리어싱 없음, 흐릿한 확대 금지.
  • 머리 실루엣을 굵고 독특하게(뿔·왕관·갈기·후드 등). 머리와 옷의 명도를 다르게 — 어두운 머리 + 어두운 옷은 작게 줄이면 덩어리로 뭉개집니다(게임에서 64px 로 축소해 씁니다).
  • 판타지·신화·역사 모티프여도 축구 선수로 먼저 읽혀야 합니다. 유니폼·축구화 필수, 무기·갑옷이 주인공이 되면 안 됩니다. 실존 선수의 이름·얼굴 금지.

캐릭터 1명당 이미지 2장

  1. <id>__portrait.png — 정사각(1024×1024). 정면 얼굴~가슴 위, 얼굴이 화면의 55~70%, 머리 장식이 잘리지 않게 사방 여백. 축구공·전신 넣지 마세요.
  2. <id>__full.png — 세로로 길게(1024×1536 이상). 정면 액션 포즈 전신, 발 근처에 축구공 1개, 팔다리가 몸통에 붙어 뭉개지지 않게.

두 장은 같은 캐릭터·같은 의상·같은 색. 캐릭터끼리 얼굴 크기와 카메라 거리를 통일하세요.

마지막에 JSON 한 덩어리 (id = 소문자 kebab-case, 이미지 순서대로)

[{"id":"ragna","name":"라그나","title":"불꽃의 스트라이커","position":"FW",
  "stars":5,"signature":"#f7a051","desc":"한 문장 설명"}]

position 은 FW/MF/DF/GK 중 하나. signature 는 아트에서 실제로 눈에 띄는 대표색 (카드 프레임이 이 색으로 구워집니다).

이번 세션의 테마와 캐릭터 목록은 다음 메시지로 전달합니다.

배치 생성 도구(Midjourney/SD)나 시트로 뽑을 때. 규격 근거 포함 — 사람이 규격을 재확인할 때도 이쪽을 본다.

5,699자 · 레퍼런스 이미지와 함께 붙여넣는다

첨부한 레퍼런스 이미지는 시각 스타일(픽셀 밀도·색감·캐릭터 톤)만 참고합니다. 레퍼런스에 보이는 카드 테두리·이름표·별·설명판·배경 패널·원형 토큰은 재현하지 마세요. 그것들은 우리 게임 엔진이 따로 합성합니다. 당신이 만드는 것은 캐릭터 아트 그 자체뿐입니다.

이번 세션의 테마와 캐릭터 목록은 다음 메시지로 전달합니다. 지금은 아래 규격만 숙지하세요.

0. 절대 규칙 (하나라도 어기면 파이프라인이 산출물을 만들 수 없습니다)

  1. 배경은 완전 투명(알파 0) PNG. 배경을 그리지 마세요. 투명 출력이 불가능한 도구라면 순수 마젠타 #FF00FF 단색 배경 + 안티앨리어싱 없는 하드 엣지로 출력하세요. 마젠타는 캐릭터 어디에도 쓰면 안 됩니다. (반투명 그라디언트 배경·어두운 패널 배경은 자동 제거가 불가능합니다.)
  2. 텍스트를 굽지 마세요. 이름·이명·희귀도·별·포지션 약어·능력치·설명·워터마크·서명 전부 금지. 모든 글자는 게임 UI 가 실제 폰트로 렌더합니다.
  3. 프레임을 굽지 마세요. 카드 테두리·금테·코너 세공·밴드·배경 패널 금지.
  4. UI 요소를 굽지 마세요. 원형 토큰, 팀 컬러 링, 선택 링, 공 소유 마커, 등번호 뱃지, 체력/상태 바 — 전부 게임 런타임이 매 프레임 그립니다. 아트에 있으면 이중으로 겹칩니다.
  5. 바닥 그림자·외곽 글로우·오라·파티클·마법진 금지. 실루엣 추출을 오염시킵니다.
  6. 캐릭터 1명당 이미지 2장(아래 §1). 여러 캐릭터를 한 장에 모은 시트는 기본 산출물이 아닙니다(불가피할 때만 §7 의 엄격 규격).

1. 산출물 — 캐릭터 1명당 PNG 2장 + 메타 1개

파일크기내용
<charId>__portrait.png정사각, 512×512 이상 (정확히 1:1)얼굴/가슴 위
<charId>__full.png세로 1:2, 512×1024 이상 (허용 1:1.6~1:2.4)전신 액션
  • charId = 소문자 ASCII kebab-case (ragna, penguin-king). 대문자·공백·한글 금지.
  • 구분자는 언더스코어 2개(__).
  • 같은 charId 의 두 장은 같은 캐릭터·같은 의상·같은 색이어야 합니다(둘을 대조해 주는 로직은 없습니다).
  • 파일로 저장이 안 되는 환경이면, 이미지마다 어떤 charId 의 어떤 variant 인지 명시하세요.

두 장이 서로 다른 사다리로 내려갑니다(같은 이미지의 크롭이 아닙니다):

  • __portrait → 얼굴 아바타 64 / 32 / 16px (경기 화면 선수 토큰)
  • __full → 전신 스프라이트 64 / 32 / 16 / 8px + 카드 일러스트

2. 메타 (기계가독 — 이미지와 함께 텍스트로 출력)

모든 캐릭터를 만든 뒤, 마지막에 JSON 배열 하나를 코드블록으로 출력하세요. 순서 = 캐릭터를 만든 순서. 누락 필드가 있으면 자동 폴백이 걸리고 색이 테마와 어긋납니다.

[
  {
    "id": "ragna",
    "name": "라그나",
    "title": "불꽃의 스트라이커",
    "position": "FW",
    "stars": 5,
    "signature": "#f7a051",
    "frame": "#c82813",
    "desc": "차원을 가르는 강슛, 필드 전체에 볼을 지핀다."
  }
]
  • position ∈ FW | MF | DF | GK (반드시 이 4개 중 하나, 대문자)
  • stars = 1~6 정수
  • signature = 캐릭터 대표색 1개(hex). 아트에서 실제로 눈에 띄는 색을 고르세요 — 카드 프레임·이펙트가 이 색으로 구워집니다. 미지정 시 "면적이 가장 넓은 채도색"이 자동 선택되는데, 실측상 12종 중 다수가 테마색과 어긋났습니다(빙하 캐릭터 → 빨간 망토색).
  • frame = 프레임 금속색(hex). 생략하면 signature 를 어둡게 깎아 씁니다.
  • desc = 한 문장. 카드 하단에 게임 UI 가 렌더합니다(아트에 굽지 마세요).

3. 구도

__portrait (정사각)

  • 정면, 시선 정면 또는 아주 약한 3/4. 목·머리 기울기 최소, 좌우 대칭에 가깝게.
  • 크롭 = 머리 장식 맨 위 ~ 가슴 위. 어깨는 살짝만.
  • 얼굴+머리가 프레임의 55~70%, 사방 5~10% 여백(장식이 잘리면 안 됩니다).
  • 머리 장식(뿔·왕관·후광·귀·모자)이 캐릭터 식별자입니다 — 절대 잘리지 않게.
  • 모든 캐릭터의 얼굴 크기·눈 높이·머리 중심을 통일하세요(한 세트로 보여야 합니다).
  • 축구공·전신·긴 무기·큰 날개 전체는 portrait 에 넣지 마세요.

__full (세로 1:2)

  • 정면 액션 포즈 1개 (달리기 / 슛 준비 / 드리블 / 태클 / 세이브).
  • 머리끝~발끝 전부 포함, 캐릭터가 세로의 85~90%.
  • 축구공 1개를 발 근처에. 공이 캐릭터를 가리지 않게.
  • 팔다리가 몸통에 붙어 뭉개지지 않게 — 8px 까지 줄여도 형태가 남아야 합니다.
  • 캐릭터마다 카메라 거리·비율을 바꾸지 마세요. 거대 종족도 다른 캐릭터와 비슷한 시각적 부피로, 작은 종족도 지나치게 작게 만들지 마세요.

4. 스타일 — 픽셀 아트 직접 생성

  • 고해상도 픽셀 아트. 픽셀 모서리 선명, 안티앨리어싱 없음, 부드러운 디지털 페인팅 금지.
  • 업스케일이 필요하면 최근접 보간(nearest-neighbor) 정수 배율만. 흐린 확대는 규격 위반입니다.
  • 미세 노이즈 픽셀 남발 금지. 면 단위 명암 + 굵은 실루엣.
  • 제한 팔레트: portrait 24색 이내, full 28색 이내 권장. 색 축소는 우리가 단계별로 합니다 (아바타 64→24색 / 32→14색 / 16→8색, 스프라이트 64→28 / 32→18 / 16→10 / 8→5색) — 당신이 미리 6~10색으로 줄이지 마세요. 원본은 풍부하게, 대신 실루엣과 대비를 확보하세요.

저해상도 생존 규칙 (가장 자주 실패하는 지점)

실측: 12캐릭터를 16px 아바타로 내렸을 때 명확히 읽힌 것은 4종뿐이었고, 실패한 4종은 전부 어두운 머리 + 어두운 복장 조합이었습니다. 가른 변수는 해상도가 아니라 실루엣의 굵기와 명도 대비입니다.

  • 머리 실루엣을 굵고 독특하게(갈기·뿔·왕관·후드 등). 얇고 산발적인 머리카락은 사라집니다.
  • 머리와 몸통의 명도를 다르게. 어두운 머리 + 어두운 옷 = 16px 에서 덩어리로 뭉개집니다.
  • 얼굴은 배경과, 배경은 의상과 명도 대비를 확보하세요.
  • 판정 기준: 눈을 가늘게 뜨고 봐도 누구인지 구별되는가.

5. 축구 선수로 읽힐 것

모든 캐릭터는 판타지/역사 인물이기 이전에 축구 선수여야 합니다.

  • 필수: 축구 유니폼(또는 유니폼으로 재해석한 의상), 축구화, 축구공(full 만), 축구 동작, 포지션 연상 자세.
  • 판타지·신화·역사·실존 인물 모티프는 머리 실루엣 / 표정 / 피부색 / 수염 / 헤어 / 종족 특징 / 유니폼 문양 / 색상 / 절제된 장식으로 표현합니다.
  • 무기·갑옷이 축구공과 축구 동작보다 커 보이면 안 됩니다. 전사가 아니라 선수로 읽혀야 합니다.
  • 실존 선수의 이름·얼굴을 쓰지 마세요.

6. 색상 제약 (게임 시스템과 충돌하는 색)

우리 런타임이 아트 위에 겹쳐 그리는 색들이 있습니다. 이 색을 캐릭터 주조색으로 쓰면 경기 화면에서 팀·상태 표시와 섞여 판독이 무너집니다.

예약된 용도색아트에서
팀 링 blue (아군)#3b82f6 / #3da9f1 계열주조색 금지 (보조·악센트는 가능)
팀 링 red (적팀)#ef4444 / #ef4f44 계열주조색 금지
공 소유 하이라이트#fde047 (형광 노랑)넓은 면적 금지
포지션 뱃지 FW/MF/DF/GK#f17869 / #57b775 / #0b90d8 / #fce148포지션을 색으로 표시하지 마세요 — 뱃지는 우리가 그립니다

또 하나: 일부 캐릭터는 색상(hue) 회전으로 변형본을 만듭니다. 이때 피부톤 대역 (H 18~48°, S 0.18~0.8, L 0.35~0.92)은 보호되어 회전하지 않습니다. → signature 와 유니폼 주조색을 이 대역 밖(예: 청록·보라·청색·자홍)으로 잡으면 변형본이 확실히 달라 보입니다. 주황·황토색 계열을 주조색으로 쓰면 변형해도 거의 안 변합니다.

7. (예외) 한 장 시트로만 출력 가능한 경우

도구가 파일 여러 장을 못 내면 시트 1장으로 받되, 자동 슬라이스가 가능한 형태여야 합니다. "빈 공간 없이 균형 있게 배치" 같은 유연한 레이아웃은 슬라이스가 불가능합니다(사람이 매번 좌표를 손으로 재야 합니다). 다음을 모두 지키세요.

  • 정확히 균일한 격자: 모든 셀 크기 동일, 모든 거터 동일, 바깥 마진 동일. 눈대중 정렬 금지.
  • 셀 크기·거터·마진·열/행 수를 픽셀 정수로 텍스트에 명시하세요. 예: cell 512×1024, gutter 32, margin 32, cols 6, rows 2, order = row-major.
  • 셀 개수 = 캐릭터 수. 빈 셀이 남더라도 격자를 무너뜨리지 마세요(빈 셀은 비워 두면 됩니다).
  • 배경은 순수 마젠타 #FF00FF 단색, 안티앨리어싱 없음. 격자선·라벨·제목·범례 금지.
  • 캐릭터 순서 = §2 JSON 배열 순서.
  • portrait 시트와 full 시트는 분리하세요(종횡비가 다릅니다).

8. 출력 전 체크리스트

  • 배경이 완전 투명(또는 순수 #FF00FF + 하드 엣지)인가
  • 이름·희귀도·포지션·설명 글자가 하나도 없는가
  • 카드 테두리·프레임·배경 패널이 없는가
  • 원형 토큰·팀 링·선택 링·공 마커·등번호가 없는가
  • 바닥 그림자·글로우·오라·파티클이 없는가
  • portrait 정사각 512+ / full 세로 1:2 512×1024+ 인가
  • 머리 장식이 잘리지 않았는가, 사방 여백 5~10% 있는가
  • full 에 축구공 1개, 정면 액션 포즈인가
  • 모든 캐릭터의 얼굴 크기·눈 높이·카메라 거리가 통일됐는가
  • 어두운 머리 + 어두운 복장 조합을 피했는가(16px 생존)
  • 파일명이 <charId>__portrait.png / <charId>__full.png, 소문자 kebab-case 인가
  • §2 JSON 배열을 이미지 순서대로 출력했는가

이 작업의 최우선 목표 두 가지

  1. 모든 캐릭터가 동일한 규격·카메라·얼굴 크기로 한 세트처럼 보일 것
  2. 각 캐릭터가 64px 얼굴 아바타까지 줄여도 누구인지 구별될 것

이제 다음 메시지의 테마와 캐릭터 조건을 이 규격대로 제작해 주세요.

A-2. 초안에 아예 없던 것 (추가) — 배경 투명 요구

초안 전체에 배경 처리 언급이 없다. 시트 1장 출력이라는 형식 자체가 불투명 배경을 전제한다. 이건 이 파이프라인에서 가장 비싼 실패 모드다:

  • PILOT-P2.md 철회 이력: 배경 제거 파라미터 자동 선택을 다섯 번 시도해 다섯 번 다 철회했다. 지표마다 반례가 있었고(largestShare 는 잔류를 못 잡고, erodedPct 는 캐릭터 99.77% 소실을 0.000 으로 통과시켰다), 결국 자동 선택 자체를 폐기했다.
  • 현재 설계: bgTol 을 사람이 눈으로 골라 incoming/<id>.json 에 박는다. 미지정이면 정확색 제거로 물러나 배경이 남는다(캐릭터를 먹느니 배경을 남긴다). 파일럿 12종의 실제 값은 localTol 4~24 / globalTol 30~255 로 소스마다 제각각이었다.
  • 즉 불투명 배경으로 들어오면 캐릭터당 사람 손이 2회(값 선택 + 육안 확인) 들어간다.
  • → §0-1 을 절대 규칙 1번으로 올리고, 불가 시 폴백을 #FF00FF 하드 엣지로 규정했다. 글로우·그림자·오라 금지(§0-5)도 같은 이유다 — 반투명 경계는 자동 제거가 불가능하다.

카드 디자인 공용 프롬프트 — hero 초안 v0 (외부 이미지 AI용, 2026-07-27)

hero: 카드 디자인은 별도 AI 에서 뽑는다. 어디서든 세션 시작 시 레퍼런스 이미지와 함께 전달할 공용 프롬프트 양식. 이 초안을 받는 입장(우리 에셋 파이프라인) 기준으로 수정하는 것이 과제. 아래는 초안 원문 그대로.

첨부한 레퍼런스 이미지를 이번 작업의 시각적 규격 참고 자료로 사용해 주세요.

레퍼런스의 기존 캐릭터나 이름을 복제하는 것이 아니라, 다음 요소만 고정 기준으로 사용합니다.

  • 가로형 캐릭터 카드 시트 구성
  • 세로형 카드의 종횡비
  • 카드 크기와 간격
  • 캐릭터 픽셀 아트 밀도
  • 카드 프레임의 정보 구조
  • 전신 캐릭터와 경기용 얼굴 아이콘의 연결 방식

이번 세션에서 별도로 전달할 테마에 맞춰 새로운 캐릭터들을 제작해 주세요.

1. 작업의 고정 요소와 가변 요소

고정 요소:

  • 카드 시트의 전체 비율
  • 카드의 세로 비율
  • 카드 크기와 정렬
  • 캐릭터가 카드 안에서 차지하는 크기
  • 픽셀 아트의 표현 밀도
  • 경기용 원형 픽셀 아이콘 규격

가변 요소:

  • 국가
  • 시대
  • 신화
  • 전설
  • 실제 인물 모티프
  • 종족
  • 의상
  • 축구 포지션
  • 캐릭터의 능력과 연출

레퍼런스의 캐릭터 내용은 고정하지 않습니다. 이번 세션에서 전달하는 새로운 테마를 우선 적용합니다.

2. 전체 결과물 규격

결과물은 가로형 캐릭터 카드 시트 한 장으로 제작합니다.

기본 구성:

  • 상단: 제목과 포지션 범례
  • 중앙: 캐릭터 카드 그리드
  • 하단: 해당 캐릭터들의 경기용 픽셀 아이콘 예시

기본 카드 수가 12장이라면:

  • 6열 × 2행
  • 모든 카드의 크기 동일
  • 모든 카드의 세로 비율 동일
  • 카드 사이의 간격 동일
  • 카드의 상단과 하단 정렬선 동일

카드 수가 달라지더라도 빈 공간 없이 균형 있게 정렬합니다.

게임 경기장, 전술판, 상점, 덱 설정 화면 등 별도의 게임 UI는 만들지 않습니다. 오직 캐릭터 카드 시트와 경기용 아이콘 예시만 출력합니다.

3. 카드 비율과 내부 구도

모든 카드는 동일한 세로형 비율을 사용합니다.

권장 카드 비율:

  • 가로 1 : 세로 1.65~1.75
  • 레퍼런스 이미지와 유사한 길고 좁은 세로 카드

모든 카드에서 캐릭터 크기를 통일합니다.

캐릭터 배치:

  • 머리는 카드 상단에서 약 12~18% 아래에 위치
  • 발은 카드 일러스트 영역 하단에서 약 5~10% 위에 위치
  • 캐릭터 전신이 잘리지 않게 배치
  • 캐릭터 높이는 일러스트 영역의 약 70~80%
  • 캐릭터마다 카메라 거리와 비율을 크게 바꾸지 않음
  • 거대한 캐릭터도 다른 카드와 비슷한 시각적 부피로 조정
  • 작은 캐릭터도 지나치게 작게 표현하지 않음

카드 내부 구조:

  • 상단: FW, MF, DF, GK 등의 포지션 표시
  • 중앙: 전신 또는 거의 전신 캐릭터 일러스트
  • 하단: 이름, 이명, 희귀도 또는 간단한 역할 영역
  • 가장 아래: 짧은 설명이나 속성 아이콘을 위한 영역

카드마다 정보 배치 구조는 동일하게 유지합니다.

4. 픽셀 아트 스타일

전체 스타일은 고해상도 픽셀 아트입니다.

  • 픽셀의 모서리가 선명해야 함
  • 부드러운 디지털 페인팅처럼 표현하지 않음
  • 지나치게 작은 노이즈 픽셀을 남발하지 않음
  • 캐릭터 실루엣이 배경과 명확하게 구분되어야 함
  • 얼굴, 머리 형태, 의상, 자세가 카드마다 구별되어야 함
  • 축구공과 축구 동작이 명확하게 보여야 함

카드 일러스트에서는 비교적 세밀한 픽셀 표현을 사용해도 됩니다. 다만 얼굴과 신체 비율은 모든 카드에서 같은 스타일로 유지합니다.

5. 축구 캐릭터 표현

모든 캐릭터는 판타지 인물이나 역사적 인물이기 전에 축구선수로 보여야 합니다.

반드시 포함할 요소:

  • 축구 유니폼 또는 축구 유니폼으로 재해석한 의상
  • 축구화
  • 축구공
  • 패스, 드리블, 슈팅, 태클, 세이브 중 하나의 축구 동작
  • 포지션을 연상시킬 수 있는 자세

판타지, 신화, 역사, 실제 인물 모티프는 다음 요소를 통해 표현합니다.

  • 머리 실루엣
  • 표정
  • 피부색
  • 수염
  • 헤어스타일
  • 종족 특징
  • 유니폼 문양
  • 색상
  • 제한된 장식
  • 캐릭터 주변의 속성 효과

무기나 갑옷이 축구공과 축구 동작보다 중요하게 보이면 안 됩니다. 캐릭터는 전사가 아니라 축구선수로 읽혀야 합니다.

6. 캐릭터별 식별 요소

각 캐릭터는 다음 항목 중 최소 3개 이상으로 구분합니다.

  • 머리 외곽 실루엣
  • 헤어스타일
  • 헤어 컬러
  • 피부색
  • 눈매
  • 눈동자 색
  • 수염
  • 귀, 뿔, 왕관, 모자 등의 머리 장식
  • 얼굴 문양
  • 유니폼 주조색
  • 유니폼 보조색
  • 포지션에 맞는 자세
  • 대표 속성 효과

같은 시트 안에서 서로 비슷한 머리와 얼굴을 반복하지 않습니다.

7. 경기용 픽셀 아이콘 제작 규격

각 카드 캐릭터마다 실제 경기 화면에 사용할 얼굴 중심 픽셀 아이콘을 함께 제작합니다.

게임 화면 전체는 만들지 않습니다. 시트 하단에 캐릭터별 아이콘 샘플만 일렬로 보여줍니다.

아이콘은 카드 일러스트와 별개의 캐릭터가 아니라, 동일한 캐릭터를 단순화한 파생 이미지여야 합니다.

아이콘 논리 해상도

기본 경기용 얼굴 스프라이트:

  • 논리 해상도 16×16px
  • 시트에서는 확인할 수 있도록 최근접 보간 방식으로 크게 확대하여 표시
  • 픽셀을 흐리게 확대하지 않음
  • 안티앨리어싱 사용 금지
  • 픽셀 경계가 선명해야 함

필요하다면 보조 원본으로 32×32px 얼굴 아이콘을 함께 설계할 수 있지만, 최종 경기용 기준은 16×16px입니다.

16×16 얼굴 스프라이트 내부 구성

  • 얼굴과 머리 중심
  • 가슴 아래 신체는 표현하지 않음
  • 어깨는 최대 1~2픽셀 정도만 허용
  • 머리와 얼굴이 캔버스의 약 75~85%를 차지
  • 상단, 좌우에 최소 1픽셀의 안전 여백 유지
  • 얼굴은 정면 또는 약한 3/4 방향
  • 캐릭터마다 시선 방향을 제각각 바꾸지 않음
  • 모든 캐릭터의 얼굴 크기를 동일하게 맞춤

아이콘 안에서 우선 보존할 요소:

  1. 머리 실루엣
  2. 헤어 또는 머리 장식
  3. 얼굴과 피부색
  4. 눈매
  5. 수염
  6. 대표 색상
  7. 작은 종족 특징

아이콘에서 제거할 요소:

  • 복잡한 배경
  • 축구공
  • 전신
  • 긴 무기
  • 큰 날개 전체
  • 오라
  • 마법진
  • 파티클
  • 카드 프레임 장식
  • 작은 액세서리
  • 읽을 수 없는 미세 문양

날개, 뿔, 왕관, 동물 귀 등 중요한 특징은 16×16에서도 알아볼 수 있도록 단순한 실루엣으로 축약합니다.

아이콘 색상 규칙

16×16 아이콘 하나에 사용하는 색상은 가급적 다음 수준으로 제한합니다.

  • 피부색: 1~2색
  • 머리색: 2~3색
  • 눈 또는 얼굴 포인트: 1색
  • 대표 장식색: 1~2색
  • 외곽선: 1색

전체적으로 약 6~10색 안에서 표현합니다.

카드의 모든 색을 축소해 넣지 않습니다. 캐릭터를 대표하는 핵심 색상만 남깁니다.

8. 원형 경기 토큰 규격

16×16 얼굴 스프라이트를 게임에서는 원형 토큰 안에 넣습니다.

권장 논리 크기:

  • 전체 원형 토큰: 24×24px
  • 내부 얼굴 스프라이트: 16×16px
  • 얼굴 주변 내부 여백: 약 2px
  • 팀 컬러 외곽 링: 약 2px
  • 바깥쪽 투명 안전 여백: 약 1px

원형 토큰의 구성:

  • 중앙: 캐릭터 얼굴
  • 내부 배경: 어두운 네이비 또는 매우 어두운 무채색
  • 외곽 링: 팀 컬러
  • 외부 장식: 최소화

팀 구분:

  • 우리 팀: 선명한 블루 링
  • 상대 팀: 선명한 레드 링
  • 중립 또는 미지정: 회색 링
  • 선택된 선수: 기존 팀 링 바깥에 얇은 금색 또는 흰색 링 추가
  • 공 소유 선수: 토큰 하단에 작은 공 마커 또는 점 표시

팀 컬러는 외곽 링에만 적용합니다. 캐릭터 얼굴이나 머리색을 팀 컬러로 변경하지 않습니다.

캐릭터의 속성, 국가, 희귀도에 따라 원형 링 색상을 바꾸지 않습니다. 링은 오직 팀을 구분하는 용도입니다.

9. 아이콘의 통일성과 가독성

모든 경기 아이콘은 한 세트처럼 보여야 합니다.

통일할 항목:

  • 얼굴 크기
  • 눈의 높이
  • 머리 중심 위치
  • 외곽선 두께
  • 빛의 방향
  • 명암 단계
  • 배경색
  • 원형 링 두께
  • 원 안의 여백

멀리서 보았을 때는 팀 컬러 링이 가장 먼저 보여야 합니다. 가까이 보았을 때는 머리 실루엣과 대표 색상으로 캐릭터를 구별할 수 있어야 합니다.

아이콘을 카드 일러스트처럼 화려하게 만들지 않습니다. 카드는 수집성과 캐릭터성을 보여주고, 경기 아이콘은 위치와 상태를 빠르게 확인하는 용도입니다.

10. 시트 하단 아이콘 샘플 표시

카드 그리드 아래에 모든 캐릭터의 경기용 아이콘을 카드 순서와 동일하게 배치합니다.

각 캐릭터마다 다음 두 가지를 보여줍니다.

  • 16×16 얼굴 스프라이트 확대본
  • 블루팀 링이 적용된 원형 토큰

공간이 충분하다면 대표 캐릭터 2~3명에 한해 다음 상태도 함께 보여줍니다.

  • 블루팀 기본 상태
  • 레드팀 기본 상태
  • 선택된 상태
  • 공 소유 상태

하지만 게임 경기장 전체 화면은 출력하지 않습니다.

11. 포지션 규칙

포지션 표기는 다음 약어를 사용합니다.

  • FW: 공격수
  • MF: 미드필더
  • DF: 수비수
  • GK: 골키퍼

포지션 색상은 전체 시트에서 통일합니다.

  • FW: 레드 또는 오렌지 계열
  • MF: 그린 계열
  • DF: 블루 계열
  • GK: 골드 또는 옐로 계열

이 포지션 색상은 카드의 작은 포지션 표시와 분류에만 사용합니다. 경기용 원형 토큰의 외곽 링에는 포지션 색상을 사용하지 않습니다.

12. 출력 전 확인사항

결과물을 만들기 전에 다음을 반드시 확인합니다.

  • 모든 카드의 가로와 세로 크기가 동일한가
  • 모든 캐릭터의 전신 크기가 유사한가
  • 카드마다 카메라 거리가 일정한가
  • 카드가 잘리거나 프레임 밖으로 나가지 않았는가
  • 카드 순서와 하단 아이콘 순서가 같은가
  • 모든 아이콘의 얼굴 크기가 같은가
  • 16×16에서도 핵심 실루엣이 남아 있는가
  • 원형 토큰 링이 캐릭터 속성이 아니라 팀을 나타내는가
  • 게임 화면이나 불필요한 UI가 포함되지 않았는가
  • 이번 세션에서 전달한 테마가 정확히 반영되었는가

이번 작업의 최우선 목표는 다음 두 가지입니다.

  1. 모든 캐릭터 카드가 동일한 규격과 비율로 보이는 것
  2. 카드 캐릭터가 일관된 16×16 경기용 얼굴 아이콘으로 변환되는 것

이제 다음 메시지에서 전달할 테마와 캐릭터 조건을 적용해 동일한 카드 시트 규격으로 제작해 주세요.
