# HMB 온라인 — 화면 인벤토리 (실물 실측)

> **근거**: 격리 풀스택(java :8085 / engine-runner :8795 / AI executor `stub` / web :5175, 데모 :8080·:5173 무접촉)을
> 실제로 띄우고 Playwright 로 **전 화면을 실제 조작·캡처**한 결과다. 좌표는 눈대중이 아니라 `getBoundingClientRect()`
> **실측값**이며, 캡처는 `design/inventory/{mobile,desktop}/` 에 있다. 재현 스크립트 = `design/tools/`.
>
> 뷰포트: **모바일 390×844**(iPhone 급, `isMobile+hasTouch`) / **데스크탑 1440×900**. 좌표 단위 = CSS px, 원점 = 문서 좌상단.
> 이 문서는 **현재 구현된 UI 의 사실 기록**이지 디자인 제안이 아니다. 스타일(색·질감·장르)은 여기서 다루지 않는다.

## 2. 화면별 실측 요소

### S01 로그인 `/login`
- 타이틀 `HMB 온라인` 상단 중앙. 그 아래 **세로 버튼 3개**(전폭 358, 높이 ~86, 간격 ~44): 「구글로 계속」·「애플로 계속」·「게스트로 시작」. 세 번째만 외곽선만 있는 약한 스타일.
- 하단 캡션 1줄: "목업 로그인입니다 — 실제 구글/애플 계정과 무관합니다."

- **닉네임 단계**: 프로바이더 배지(`게스트` pill) + "계정 닉네임을 입력하세요" → 라벨 `닉네임` + 입력 `358×~78` + 전폭 「계속」.
- **스타터팩 모달**: "스타터 팩 지급 / 신규 감독님을 환영합니다! 선수 14명과 3,000P가 지급되었습니다." + 중앙 작은 「확인」.

- **WAITING 상태**: 헤더 `슬롯 N` + 우측 `대기 중` 배지 `50×22` → 점선 박스 안 `다음 선수까지` + **큰 카운트다운**(`72:00:00`) → 하단 `단축 비용 ● 3,600 P` + 「포인트로 단축」 `95×36`(우측 정렬). 포인트 부족 시 버튼 아래 붉은 경고문.
- **OPEN(FA 영입)**: 배지가 `FA 영입` 으로 바뀌고 → **영입 대상 선수 카드**(금 테두리 강조 박스: 포지션 · 이름 굵게 · 등급 · **능력치 5행 가로 막대**(기술/피지컬/패스/슈팅/스피드) + 수치) → `선수 가치 1868` → **제안 빌더**: `내 선수 제안 (N)` + 내 선수 **칩 그리드**(선택 시 테두리 강조) → `함께 낼 포인트: 0 P` + 슬라이더 → 캡션("성공 확률은 제안을 보낸 뒤 결과로 공개됩니다") → 전폭 「제안 보내기」.
- OPEN-TRADE 변형은 요구/대가 비교 + 수락/거절.

### S13 로그·랭킹 `/logs`
- **탭 3개(role=tab)**: 경기 `16,70 117×43` / 트레이드 `137,70` / 랭킹 `257,70` — 선택 탭 하단 밑줄. 데스크탑은 각 `360×43`.

### S14 리그 `/league`
- **시즌 없음**: 안내 카드 `16,70 358×216` ("리그에 도전하세요 / 봇 9팀과 더블 라운드로빈 18라운드…") + 「리그 시작」 `32,202 326×52`
- **대시보드**: 상단 **다음 경기 카드**(파란 테두리 강조) — `R1` 라운드 배지 + `내 팀 (홈) vs 상대` + 전폭 「다음 경기」 CTA

## 4. 관측 메모 (디자인 판단 아님 · 사실만)
- 스택 기동 시 `apps/web/scripts/ensure-viewer.mjs` 를 돌리지 않으면 뷰어 iframe 이 SPA 자기 자신을 로드해 **뷰어 자리에 앱 화면이 중첩**돼 보인다(캡처 `21`,`25` 가 그 상태). `npm run dev` 는 predev 로 자동 실행되지만 `npx vite` 직접 실행 시엔 누락된다.
