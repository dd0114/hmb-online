덱세팅 화면 개편 — 직접 만져보는 목업 #455 A-0

이 파일은 정적 HTML 한 장입니다(서버·외부 연결 0). 진짜 화면이 아니라 동작을 먼저 확인하려고 만든 것 — 여기서 컨펌해야 A1~A4 개발을 시작합니다.

hero 가 해볼 것 (프로토타입 탭)

  1. 선수 꾹 누르기 → 드래그드롭 — 0.15초 참으면 잡힙니다(링이 돕니다). 다른 선수 위에 놓으면 자리가 맞바뀝니다.
  2. 선수 한 번 누르기 → 메뉴 — 메뉴 4항목이 무엇이어야 하는지가 질문 1번입니다(탭에서 안을 바꿔가며 만져보세요).
  3. 한마디(프롬프트) 입력 — 메뉴에서 열어 직접 타이핑해 보세요. 저장하면 선수 왼쪽 위에 초록 점이 붙습니다.
  4. 자동 채우기 / auto — 빈칸을 만들면 경기장 우측 하단에 [자동 채우기]가 나타납니다. 상단 [auto]는 항상 최고 전력으로 다시 짭니다(질문 2번).
  5. 경기장 세로 비율 — 옆의 슬라이더로 바꿔가며 "이 정도면 이름이 안 겹친다" 지점을 골라주세요(질문 3번).

보유 선수 자리 경기장이 쓰고 남는 세로 전부 —
"벤치가 비었다"의 기준은 벤치 앞 3칸으로 잡아 뒀습니다(총 7칸을 다 채우라고 하면 버튼이 늘 떠 있게 됩니다). 이 숫자는 나중에 얼마든지 바꿀 수 있습니다.
현재 출하 화면의 폰 경기장 비율은 68 : 44(세로가 짧은 폰은 68 : 40) 입니다. 슬라이더 기본값 68 : 60 이 이번 제안이고, 숫자가 클수록 경기장이 세로로 깁니다.

질문 1

선수를 한 번 누르면 뜨는 메뉴, 무엇이 들어가야 하나요?

원문에 '위치 이동' · '프롬프트' · '선수 이동' · '선택 취소' 네 개가 적혀 있는데, 설명이 서로 뒤섞여 있어 그대로 만들면 두 항목이 같은 일을 합니다.
"누르면 '위치 이동' , '프롬프트', '선수 이동', '선택 취소' 버튼이 있어. 위치 이동 누르면 프롬프트로 스크롤 다운해서 보여져, 선수 이동 누르면 현재 보드에 포메이션칸 + 벤치자리 활성화되고 누르면 바뀌어. 선수 정보 누르면 선수 스탯이랑 강화 할수 있어."

즉 실제로 필요한 동작은 ①한마디 쓰기 ②자리 옮기기 ③선수 정보·강화 ④닫기 네 가지로 보입니다. 이름과 개수를 골라주세요 — 고르면 프로토타입 메뉴가 바로 바뀝니다.

고른 뒤 프로토타입 탭으로 돌아가 선수를 눌러 보세요. 세 안 다 실제로 눌러볼 수 있습니다.
질문 2

[auto] 를 누르면, 선수들에게 써둔 한마디는 어떻게 되나요?

"초기화 대신에 새로 auto로 할거야 … 현재 가진전력에서 최선으로 배치해주는거야. … 주로 뽑기하고 사용하면되게"

auto 는 11명을 처음부터 다시 짭니다 — 뽑기로 좋은 선수가 들어오면 그 선수가 자리를 가져가고, 밀린 선수는 벤치로 갑니다. 이때 이미 써둔 한마디(프롬프트)를 어떻게 할지가 결정거리입니다. 예전에 이걸 정하지 않아 한마디가 통째로 날아간 사고가 있었습니다.

프로토타입 상단 [auto] 를 누르면 고른 안대로 동작하고, "몇 명의 한마디가 유지/덮어써졌는지"를 알려줍니다.
질문 3

경기장을 세로로 얼마나 늘릴까요?

"전술보드가 좁아서 선수들 이름이 겹쳐 그냥 화면 한칸 다 쓰자. 지금 화면 기준상 보유선수가 가장 하단으로 보여지고 경기장은 세로로 더 늘려서 비율 맞추자."

프로토타입 옆 슬라이더로 직접 바꿔보고 이름이 안 겹치는 최소 지점을 골라 주세요. 경기장을 늘린 만큼 아래 보유 선수 목록이 짧아집니다(둘이 같은 세로를 나눠 씁니다).

슬라이더를 움직이면 이 선택도 같이 바뀝니다(4 단위). 최종값은 요약 탭에 남습니다.
