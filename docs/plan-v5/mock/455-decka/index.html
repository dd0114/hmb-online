덱세팅 화면 개편 — 직접 만져보는 목업 #455 A-0

이 파일은 정적 HTML 한 장입니다(서버·외부 연결 0). 진짜 화면이 아니라 동작을 먼저 확인하려고 만든 것 — 여기서 컨펌해야 A1~A4 개발을 시작합니다.

hero 는 만져보고 "OK" 아니면 "다르다" 만 주시면 됩니다 — 고를 것은 없습니다

  1. 선수 꾹 누르기 → 드래그드롭 — 0.15초 참으면 잡힙니다(링이 돕니다). 다른 선수 위에 놓으면 자리가 맞바뀝니다.
  2. 선수 한 번 누르기 → 메뉴 — [자리 옮기기] [한마디 쓰기] [선수 정보] [닫기] 네 개(정한 것 ①).
  3. 한마디(프롬프트) 입력 — 메뉴에서 열어 직접 타이핑해 보세요. 저장하면 선수 왼쪽 위에 초록 점이 붙습니다.
  4. 자동 채우기 / auto — 빈칸을 만들면 경기장 우측 하단에 [자동 채우기]가 나타납니다. 상단 [auto]는 최고 전력으로 다시 짜되 써둔 한마디는 건드리지 않습니다(정한 것 ②).
  5. 경기장 세로 비율 — 이제 남는 세로를 전부 씁니다(정한 것 ③). 옆 슬라이더로 고정값도 비교할 수 있습니다.
  6. 보유 선수 = 모달 — 빈 자리를 누르면 그 포지션으로 바텀시트가 올라옵니다(하단 [👥 보유 선수] 로도 열림). R3 에서 되돌린 것
  7. 팀 프롬프트 · 포메이션 — 벤치 아래 [팀 지시] 칸, 상단 4-4-2 ↔ 4-3-3 선택기. R3 에서 새로 넣은 것
①②③ 은 이미 정해서 화면에 켜 뒀습니다. 탭에 "왜 그렇게 정했나"와 다른 안 만져보기 가 있으니, 만져보고 다르게 느껴질 때만 바꿔보시고 그 결과를 알려주세요.

정한 것 ①

선수를 누르면 뜨는 메뉴 = A안 — 자리 옮기기 / 한마디 쓰기 / 선수 정보 / 닫기

왜 이렇게 정했나: 원문에 '위치 이동' · '프롬프트' · '선수 이동' · '선택 취소' 네 개가 적혀 있는데, 설명이 서로 뒤섞여 있어 그대로 만들면 두 항목이 같은 일을 하고 '선수 정보'(강화 진입점)가 들어갈 자리가 없어집니다. 그래서 겹치는 둘을 하나로 합치고 그 자리에 선수 정보를 넣었습니다.
"누르면 '위치 이동' , '프롬프트', '선수 이동', '선택 취소' 버튼이 있어. 위치 이동 누르면 프롬프트로 스크롤 다운해서 보여져, 선수 이동 누르면 현재 보드에 포메이션칸 + 벤치자리 활성화되고 누르면 바뀌어. 선수 정보 누르면 선수 스탯이랑 강화 할수 있어."

즉 실제로 필요한 동작은 ①한마디 쓰기 ②자리 옮기기 ③선수 정보·강화 ④닫기 네 가지입니다. 메뉴 이름·개수는 상수 한 줄이라 언제든 바꿀 수 있으니, 나중에 [명단에서 빼기]가 필요해지면 C안으로 켜면 됩니다.

다른 안도 눌러볼 수 있습니다 (고르면 프로토타입 메뉴가 즉시 바뀝니다)
고른 뒤 프로토타입 탭으로 돌아가 선수를 눌러 보세요. 세 안 다 실제로 눌러볼 수 있습니다.
정한 것 ②

[auto] 와 써둔 한마디 = ㄴ안 — 쓴 문장은 절대 안 건드리고, 빈 칸만 채운다

"초기화 대신에 새로 auto로 할거야 … 현재 가진전력에서 최선으로 배치해주는거야. … 주로 뽑기하고 사용하면되게"

auto 는 11명을 처음부터 다시 짭니다 — 뽑기로 좋은 선수가 들어오면 그 선수가 자리를 가져가고, 밀린 선수는 벤치로 갑니다.

왜 이렇게 정했나: 예전에 한마디가 통째로 날아간 사고가 있었습니다(ㄷ안 = 그 사고와 같은 동작이라 영구 기각). 남은 것은 "손 안 댐(ㄱ)" 과 "빈 칸만 채움(ㄴ)" 인데, 지금 [자동 채우기] 가 이미 빈 칸만 채우는 규칙으로 돌고 있습니다 — 두 버튼이 같은 규칙을 쓰면 유저가 규칙을 하나만 배우면 됩니다. 뽑기 직후 바로 경기에 들어갈 수 있는 것도 ㄴ안입니다.

다른 안도 눌러볼 수 있습니다 (고른 뒤 프로토타입에서 [auto] 를 눌러 보세요)
프로토타입 상단 [auto] 를 누르면 고른 안대로 동작하고, "몇 명의 한마디가 유지/덮어써졌는지"를 알려줍니다.
정한 것 ③

경기장 세로 = 남는 세로를 전부 (지금 출하값은 68 : 44 고정)

"전술보드가 좁아서 선수들 이름이 겹쳐 그냥 화면 한칸 다 쓰자. 지금 화면 기준상 보유선수가 가장 하단으로 보여지고 경기장은 세로로 더 늘려서 비율 맞추자."

R3 에서 바뀐 것: 보유 선수를 모달(바텀시트)로 되돌리면서 화면 아래가 비었습니다. 그래서 고정 비율(68:60)을 버리고 경기장이 벤치·팀 지시가 쓰고 남는 세로를 전부 가져가게 했습니다 — "화면 한칸 다 쓰자" 에 가장 가깝습니다. 실제로 그려진 비율은 옆 실측 값으로 보여 드립니다(추정 아님).
