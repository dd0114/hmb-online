## A. 메이플스토리 잠재능력·큐브 조사 (출처 명시)

### 구조
- **잠재능력 등급(티어)**: 레어 → 에픽 → 유니크 → 레전드리. 등급이 높을수록 좋은 옵션 테이블.
- **옵션 3줄**: 1번째 줄 = 아이템 잠재 등급과 **동일 등급** 옵션. 2·3번째 줄 = 기본은 **한 단계 낮은 등급**, 일정 확률("이탈 옵션")로 동일 등급이 뜬다.
- **큐브 = 잠재 재설정 아이템**. 굴릴 때마다 3줄 랜덤 재설정 + 낮은 확률로 **등급 승급**.

### 공식 확률 (넥슨 공지 2021-03-05, KMS)
| 승급 | 레드 큐브 | 블랙 큐브(상위 캐시) | 에디셔널 |
|---|---|---|---|
| 레어→에픽 | 6.0% | **15.0%** | 4.76% |
| 에픽→유니크 | 1.8% | **3.5%** | 1.96% |
| 유니크→레전드리 | 0.3% | **1.0%** | 0.50% |

- 2·3줄 "동일 등급 이탈" 확률: 레드 10%/1%, 블랙 20%/5%.
- **천장**: 등급 상승 기댓값의 **1.5배** 개수를 써도 승급 못 하면 다음 큐브에서 100% 승급 (KMS 확률형 규제 이후).
- 옵션 중복 제한: 특정 옵션은 3줄 중 최대 1회(올스킬+) 또는 2회(보공%)만 등장.
- 큐브 위계: 캐시 큐브(레드/블랙)가 승급률·이탈률 모두 우위. 인게임 재화 큐브(장인/명장)는 도달 가능 등급 자체가 캡(장인=유니크까지 등).

### 설계 함의 (HMB가 훔칠 것)
1. **"굴리는 재미"의 본체 = 3줄 조합 + 낮은 승급 확률** — 매 롤이 복권이면서 등급이 랙칫(내려가지 않음).
2. **줄 구조(1줄=티어, 2·3줄=한 단계 아래+이탈)**가 "같은 에픽이어도 질이 다르다"를 만든다 → 파고들 깊이.
3. **천장(1.5배 보장)**은 한국 확률형 규제 표준 — HMB도 확률 공개+천장 필수(카드 조사 §1.2-5와 동일 결론).
4. 캐시/무과금 큐브의 **역할 분리**가 과금 설계의 본체.

## B. HMB 개정 모델 (hero 지시 + 조사 반영)

기존 2트랙(강화 포인트/성장 경기)을 **3축**으로 재편한다. "천장+속도" 원칙(G-D8)은 유지.

```
① 스탯 성장 (경기·무과금)     매 경기, 프롬프트+실제 플레이 → 해당 스탯 XP → 스탯별 레벨 (지수 비용)
② 성 ★ (중복·수집)           중복 카드로 2★→3★→4★ 승급 = 스탯 상한 개방 + 잠재 티어 캡 해제
③ 잠재능력 (다이스·과금+그라인드) 2★부터 3줄 랜덤 옵션. 레어<에픽<유니크. 다이스로 리롤/승급
```

### ① 스탯 성장 — 경기가 스탯을 직접 키운다 (지수 곡선)
- **매 경기 정산**: 스탯별 XP 적립. 양 = **프롬프트 지령 × match-log 실제 이벤트**(execMatch를 스탯 단위로 세분화). 예: *세트피스 헤딩 노려* 지시 + 실제 헤딩 슛 이벤트 → `shooting`·`positioning` XP. *빠른 침투* → `pace` XP.
- **스탯별 레벨**: 스탯 Lv N → N+1 비용 = `xpLvBase × xpLvGrowth^N` (**지수**). 9→10Lv은 1→2Lv과 비교불가하게 비쌈(hero 지시). 단순 지수 채택.
- 레벨업 = 자동(임계 도달 시). 스탯 +1씩. **미출전 선수 성장 0**(hero 확정 — "뛴 선수만 큰다", benchGrowthMult 폐지).
- **상한**: 현재 성(★)이 개방한 밴드 상한. 기존 등급 밴드 재사용.
- 기존 **강화(포인트→enhance_level) 시스템은 폐기** — 스탯 성장이 그 자리를 대체. 게임포인트 sink는 노말 다이스 구매로 이동(③).

### ② 성(★) — 중복 = 천장 전용 (기존 한계돌파의 개칭·확장)
- 성 승급 = **동일 카드 중복 N장 소모** (돌파와 동일 메커니즘, 명칭·UI를 ★로 통일).
- **등급별 최대 성**: **LEGEND = 4★ / DIA = 3★ / GOLD·SILVER·BRONZE = 2★** *(hero 문장 "가장 높은 등급만 4성, 그 아래 3성, 그 아래 2성"의 해석 — D-M1 확인 필요)*.
- 성이 여는 것: ⓐ 스탯 상한(밴드) 확장 ⓑ **잠재 티어 캡**: 2★=레어까지 · 3★=에픽까지 · 4★=유니크까지 *(hero: 2성은 유니크 불가, 3성은 에픽까지)*.
- 1★(기본) = 잠재 잠금. **2★부터 잠재 해금** — "중복 1회는 전 등급에 의미"(리텐션).

### ③ 잠재능력 — 메이플 이식 (HMB 번안)
- **3줄 랜덤 옵션**, 티어 레어 < 에픽 < 유니크 (메이플 4티어에서 레전드리 제외한 3티어 — 스케일 절약).
- **줄 구조 = 메이플 그대로**: 1줄 = 현재 티어, 2·3줄 = 한 단계 아래(+이탈 확률로 동일 티어). 상위 티어 테이블이 하위보다 좋음.
- **옵션 풀** (기존 시스템 훅 재사용 — 신규 엔진 개발 0):
  | 옵션 유형 | 효과 | 훅 |
  |---|---|---|
  | 능력치 %(비율) | 예: 슛 +6% | SelectData 주입 시 서버 계산 |
  | 능력치 절대값 | 예: 스피드 +4 | 〃 |
  | 회복 | 컨디션 롤 보정/회복↑ | **P2-D5 컨디션** |
  | 팀 사기 증진 | team_morale 기여↑ | **P2-D7 관계 3축** |
  | (후속) 세트피스·특수 | 지시 카탈로그 연동 | P2-D6 |
- 옵션 중복 제한(같은 옵션 3줄 독점 금지) = 메이플 규칙 이식.

### 다이스 (큐브 아날로그) — 캐시/노말 역할 분리
| | **노말 다이스** (게임포인트 구매) | **캐시 다이스** (미라클 큐브 아날로그) |
|---|---|---|
| 옵션 테이블 | 낮은 확률(좋은 옵션 드묾) | **좋은 옵션 확률↑** |
| **티어 승급** | **가능** (레어→에픽→유니크, 낮은 확률) | *(제안)* 불가 — 티어 내 품질 전용 |
| 획득 | **게임포인트 상점** (포인트 sink 이동) | 캐시(후속 — 지금은 포인트 고가 판매로 목업) |
- hero 문장 그대로: 노말 = "확률 낮은 **대신 승급 기회**", 캐시 = "좋은 스탯 테이블 확률↑". → **승급은 그라인드(노말)의 몫, 캐시는 품질** — 메이플과 반대로 비틀어 무과금 노가다에 고유 가치를 부여(D-M2 확인).
- **확률 공개 + 천장**(승급 기댓값 1.5배 보장) = 한국 규제 표준 이식.
- **결정론**: 다이스 롤 = 가챠와 동일 패턴(SecureRandom seed를 `dice_rolls`에 저장 — 감사·재현). 엔진 무변경.

### 유지되는 것
- 이중 트랙 철학(경기=성장, 중복=천장), 과금=천장+속도(G-D8), 결정론(server 권위·리플레이 bit-identical), 시안3 카드 표시(성★ = 기존 돌파★ 슬롯 재사용), 성장 리포트, FM식 "뛰어야 큰다"(영입→성장→방출 사이클).

## D. 등급 구간 설계 — 3안 (hero 목표 반영, 2026-07-26 개정)

> **hero 목표**: 무과금 = 올골드 + 다이아 1~2개 완성 / 과금 = 선발 11 중 다이아 6~7 / 레전드 = 팀당 1~2, 육성 비효율(트로피+즉전력) / 실버·브론즈 = 초반 학습용 급성장 체감 / **전 등급 4★ 가능** — 등급 격차는 성이 아니라 **잠재 티어 캡 + 잠재 줄 수**로 컨트롤. 기존 D-M1(등급별 성 캡)은 폐기.

**공통 (모든 안)**
- 성: 전 등급 1★~4★. 성 = 스탯 성장 천장 개방(밴드 내 구간 해제). 잠재 해금 = 2★.
- 스탯 밴드는 기존 등급 밴드 유지(GOLD 60–75 · DIA 70–85 · LEGEND 80–95) — 기본 격차의 바닥.
- 잠재 3줄 구조(1줄=티어, 2·3줄=한 단계 아래+이탈)는 메이플 그대로.
- **실버/브론즈 급성장**: 스탯 XP 임계 ×0.4(몇 경기마다 레벨업 체감) + 중복이 흔해 성도 금방 → 시스템 학습용.
- **레전드 비효율**: 중복 자연 희소(가챠 2%) + 성장 XP 계수 ×3 → 성·성장 다 비쌈. base가 이미 80~95라 1★로도 즉전력 = "논외" 컨셉 성립.

### 안 ㄱ — 등급 분리형 ("잠재를 승급과 아예 별개로")
잠재 티어 캡·줄 수 전부 **등급이** 정함. 성은 순수 스탯 천장.
| 등급 | 줄 수 | 티어 캡 |
|---|---|---|
| BRONZE/SILVER | 1줄 | 레어 |
| GOLD | 2줄 | 에픽 |
| DIA/LEGEND | 3줄 | 유니크 |
- 👍 규칙 최단순. 골드는 2★만 되면 바로 에픽 도전(무과금 진입 빠름).
- 👎 **성(중복)의 보상이 스탯 천장뿐** — 중복 소모 동기 약함. 3★·4★의 감흥이 밋밋.

### 안 ㄴ — 성 게이트형 ★권장 (hero 직감: "에픽은 3성부터")
줄 수 = 등급, **티어 캡 = min(등급 캡, 성 캡)**.
| | 줄 수(등급) | 티어 캡(등급) | 성 캡 |
|---|---|---|---|
| BRONZE/SILVER | 1줄 | 레어 | 2★=레어 |
| GOLD | 2줄 | **에픽** | 3★=에픽 |
| DIA/LEGEND | 3줄 | **유니크** | 4★=유니크 |
- 진행 사다리: 2★ 해금(레어) → 3★ 에픽 개방 → 4★ 유니크 개방(다이아↑만 의미).
- 👍 성 승급마다 극적 보상(새 티어) = **중복 소모 동기 최강**. 골드 4★도 의미(스탯 천장+에픽 완성). 과금 그라디언트 명확: 유니크는 다이아 전용 꿈.
- 👎 이중 캡이라 규칙 한 줄 더. 골드에 유니크 꿈이 없음 — 단 hero 목표(무과금=골드 실속+다이아 1개에 꿈)엔 부합.

### 안 ㄷ — 성=줄수형
**줄 수를 성이** 정함(2★=1줄, 3★=2줄, 4★=3줄), 티어 캡 = 등급(골드=에픽, 다이아↑=유니크).
- 👍 성 승급 보상이 직관적(줄+1). 규칙 이해 쉬움.
- 👎 2★가 1줄뿐이라 잠재 첫 체험이 빈약. 골드 4★=에픽 3줄이 다이아 3★(유니크 2줄)과 근접 — 격차 흐려질 수 있음.

### 엔드게임 파워 스케치 (안 ㄴ, 초안 수치)
잠재 줄 값 초안: 레어 +2% · 에픽 +4% · 유니크 +7% (능력치% 기준, 절대값·회복·사기 옵션은 환산 등가).
| 페르소나 | 팀 구성 | 유효 OVR 추정 |
|---|---|---|
| 무과금 완성 | 골드 4★ 에픽완성(75×~1.06≈79.5) ×10 + 다이아 완성(85×~1.15≈93) ×1 | **≈ 80.7** |
| 과금 완성 | 다이아 4★ 유니크완성(≈93) ×7 + 골드(≈79.5) ×4 | **≈ 88** |
- 격차 ≈ 9% — 전술계수·컨디션·상성으로 업셋 가능한 밴드(4-세그먼트 목표 45~65% 승률과 정합). 유니크 2~3줄 "이탈 대박"은 초저확률 고래 추격전으로 남음.
