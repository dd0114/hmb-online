## 1. 시스템 계획

### 1.1 두 트랙 (같은 카드에 누적)
```
가챠 트랙(과금 친화)   뽑기 → 중복 → 강화(+) / 한계돌파(등급 상한 개방)
                                    ↑ 동일선수 중복 = 재료
경기 트랙(무과금 친화)  기용 → 프롬프트 지령대로 활약(execMatch) → match_xp → 밴드 채움
                                    ↑ 방향 = 자연어 프롬프트 (HMB 고유)
가속(G-D8 속도)        에너지/육성 티켓/부스터 = 경기 트랙·각인 축적을 빠르게(과금)
복리(v3)               각인 = 키운 결과를 계정 자산으로(우마무스메 계승 번안)
```

### 1.2 성장 상한 규칙 (핵심 — 밸런스의 근간)
카드의 **유효 스탯 = 기본 롤 + 채움(fill)**, `채움 ≤ 현재 상한(cap)`.

| | 무과금 | 과금 |
|---|---|---|
| **cap(천장)** | 자기 등급 밴드 상한 (예 BRONZE 55) | 한계돌파로 **다음 등급까지 개방**(승급) |
| **fill(채움)** | 경기 성장(플레이) — 느림 | 경기 성장 + **속도 가속**(에너지 등) |

> **불변식**: 과금은 cap을 올리고, 플레이가 fill을 채운다. **과금만으로는 fill이 안 채워진다**(미완성) — 우마무스메 원리. 이 한 줄이 P3(소플·과금)를 "고성능 미완성"으로 만들어 밸런스를 만든다.

### 1.3 팀 전투력 모델 (곱셈 — 단일 축 지배 방지)
현 AC-B5(팀 파워=선발 11 능력치 합) 위에 실전 보정을 곱한다:

```
팀 전투력 ≈ Σ(선수 유효스탯) × 전술계수 × 컨디션계수 × (1+각인시너지)
             └ 스탯 = base+fill      └프롬프트   └훈련강도   └계정 누적(v3)
```

| 인자 | 무엇이 산다 | 돈으로 사나? |
|---|---|---|
| **유효스탯 cap** | 과금(한계돌파·고등급) | ✅ 천장 |
| **유효스탯 fill** | 플레이(경기 성장) + 과금 속도 | ◐ 가속만 |
| **전술계수** | **프롬프트 숙련(경험)** | ❌ **못 삼** |
| **컨디션계수** | 훈련강도 운영(플레이 관여) | ◐ 일부 |
| **각인시너지** | 플레이 누적(v3) + 과금 속도 | ◐ 가속만 |

→ **돈이 못 사는 축(전술계수·순수 누적)이 존재**해야 무과금·다플이 이길 길이 생긴다. 이게 4-세그먼트 밸런스의 기계적 근거다.

## 3. 대전 시나리오 — 6개 매칭 (우세 / 언더독 승리법 / 어떻게 가능)

> 원칙: **인접 세그먼트(한 축만 다름)는 접전**이어야 하고, **대각선(두 축 다름, P1↔P4)은 매칭으로 회피**한다. 어떤 조합도 "무조건 승/패"가 아니라 **행위주체성(agency)** 이 있어야 한다.

### ① 🔥 P2 장인 vs 💳 P3 라이트지갑 — ★ "시간 vs 돈"의 핵심 대결
**가장 중요한 매칭.** 낮은 천장·완전 완성(P2) vs 높은 천장·미완성(P3).

- **P3이 이기는 법**: 천장 우위. 미완성이라도 **DIA/LEGEND raw 스탯**이 P2의 밴드 상한(GOLD ~75)을 넘으면 개별 스탯 우위. **소수 정예 집중 육성**(11명 중 핵심 3~4명에 티켓 몰빵)으로 슈퍼스타 캐리.
- **P2가 이기는 법**: ①**11명 균질 완성** — P3은 핵심만 키워 벤치·롤플레이어가 구멍(약한 고리). 엔진은 11명이 다 뛰므로 약한 선수가 실점 요인. ②**전술계수** — 프롬프트 숙련으로 execMatch 질이 높아 같은 스탯이 더 강함. ③컨디션 운영 + 각인 시너지.
- **어떻게 가능한가(메커니즘)**: §1.3 곱셈 모델 + **약한 고리 패널티**(팀 파워가 합만이 아니라 최저 선수에도 의존) + **완성 게이트**(P3 미완성 구조적). → **둘 다 이길 길이 있는 진짜 접전.** 밸런스 목표 = 승률 45~55%.

### ② 🐋 P1 코어고래 vs 🔥 P2 장인 — "천장 격차를 전술로 좁히기"
- **우세**: P1(천장·fill·각인 전부 우위). P2는 전술계수만 대등.
- **P2가 이기는 법**: 천장 차이를 **전술계수 + 각인 시너지 + 상성 프롬프트**로 좁힘. P1이 안일한 프롬프트(전술계수 방심)면 업셋 가능. P2는 "돈으로 못 사는 축"에서만 앞서므로 **거기에 올인**.
- **어떻게 가능**: 천장 기여를 **로그 스케일**로 캡(스탯 격차가 승률 격차로 선형 증폭되지 않게) → "압도"가 아니라 "근소 우세". 목표 승률 P1 55~65%.

### ③ 🐋 P1 vs 💳 P3 — "둘 다 과금, 갈림은 완성도"
- **우세**: P1(같은 높은 천장 + 완전 fill + 전술). 
- **P3이 이기는 법**: **더 높은 천장**(추가 과금으로 LEGEND 확보해 P1 초과) 또는 **극단적 선택과 집중**(짧은 플레이를 핵심 카드에 고효율 투자). P1도 방심하면 raw 천장 차로 역전.
- **어떻게 가능**: 과금은 cap을 사지만 fill·전술은 여전히 플레이 → P3이 돈을 더 써도 **완성은 플레이가 필요** → P1 우위 유지되되 P3에게 "돈으로 천장 초과" 탈출구. 목표 P1 60~70%.

### ④ 🔥 P2 vs 🌱 P4 — "같은 무과금, 앞과 뒤"
- **우세**: P2(채움·전술·각인 전부 앞섬). 같은 트랙의 선배.
- **P4가 이기는 법**: 정면은 어려움 → **매칭 회피가 1차 답**(티어). 붙는다면 P4의 신선한 컨디션 운영/상성 프롬프트 + P2 방심. 본질은 "P4가 시간을 들여 P2를 따라잡는 중".
- **어떻게 가능**: 시간이 답. **각인·경기 성장이 누적**이라 P4도 계속 강해짐 → 좌절이 아니라 **추격 서사**. 목표 P2 65~75%(+ 매칭으로 빈도 최소화).

### ⑤ 💳 P3 vs 🌱 P4 — "같은 소플, 갈림은 지갑"
- **우세**: P3(천장 우위). 둘 다 미완성이라 **fill·전술은 도토리** → 순수 천장 차만 남음.
- **P4가 이기는 법**: P3이 라이트라 **방치**(과금만 하고 안 키움)면, P4의 **꾸준한 무료 성장 + 프롬프트**가 근접. P3의 미완성 고등급 vs P4의 조금 채운 저등급이 겹치는 구간.
- **어떻게 가능**: 소플끼리라 둘 다 fill이 얕음 → **cap 차이가 즉시 전투력 차로 안 벌어짐**(fill이 없으니 cap이 놀고 있음). 라이트지갑의 약점(안 키움)을 정확히 찌름. 목표 P3 55~65%.

### ⑥ 🐋 P1 vs 🌱 P4 — "대각선: 붙이지 않는 게 설계"
- **우세**: P1 압도. **정면 승부는 P4에게 사실상 불가.**
- **설계 답**: **매칭으로 회피.** 리그 티어·파워 밴드 매칭으로 이 조합의 빈도를 최소화(현 리그의 봇전 간이결과와 같은 철학 — 격차 큰 상대는 시뮬 대신 정산). PvP도 파워 매칭. P4가 P1을 만나는 건 예외적 상황(랭킹 최상위 도전 등)이고, 그땐 패배가 정상이되 **보상·핸디캡으로 완충**.
- **어떻게 가능**: 밸런스는 "P4가 P1을 이기게"가 아니라 **"P4가 P1을 자주 안 만나게"** 로 푼다. 유일하게 매칭이 답인 매칭.

### 동일 세그먼트끼리
전투력이 근사 → **전술계수(프롬프트)·컨디션 운영·각인 시너지가 승부** = 실력·운영 게임. 가장 건강한 대전. 목표 50:50.

## 4. 밸런스를 가능케 하는 설계 장치 (7개)

1. **곱셈 파워 모델**(§1.3) — 돈은 스탯만, 전술·누적은 플레이. 단일 축 지배 차단.
2. **완성 게이트**(§1.2 불변식) — 과금으로 천장 열어도 fill은 플레이. 소플과금 = 구조적 미완성.
3. **약한 고리 패널티** — 팀 파워가 합만이 아니라 최저 선수에도 의존(11명 다 뛰는 엔진 특성). 소수 초강캐 < 균질 완성인 국면.
4. **로그 스케일 천장 기여** — 스탯 격차가 승률로 선형 증폭 안 되게. 고래 우세는 "근소".
5. **밴드 상한 vs 등급 천장** — 무과금은 밴드 상한까지 완성. "완성 GOLD"가 "미완성 DIA"와 겹치는 역전 구간 존재.
6. **전술계수 = 돈으로 못 사는 축** — 프롬프트 숙련. 무과금·다플의 궁극 무기.
7. **파워 매칭·티어** — 대각선(P1↔P4) 회피. 격차 큰 조합은 빈도 최소화 + 완충 보상.

전부 **config·엔진 무관**(§2-4·§2-5). 결정론 불변: 성장·컨디션·과금 정산은 server-java 권위·멱등, 엔진 변경 0, 과거 match-log 재생 bit-identical.

## 5. 밸런스 검증 계획 (측정 가능하게)

밸런스가 "말"이 아니라 **숫자로 증명**되어야 한다:

- **4-세그먼트 대전 하네스**(`tools/` 또는 servants 테스트): 각 세그먼트를 대표하는 팀 상태(cap/fill/전술/각인 프로파일)를 파라미터화 → 6개 매칭 × N시드 시뮬 → **승률 밴드 검증**.
  - 합격 밴드(초안, 튜닝 대상): 인접 매칭 45~65%, 동일 세그먼트 45~55%, 대각선은 매칭 회피로 빈도 자체를 캡.
- **회귀 가드**: 밸런스 config 변경 시 승률 밴드 이탈 = FAIL(파울/슛 밴드 회귀 가드와 동형).
- **완성 게이트 검증**: "과금만(높은 cap·낮은 fill)"이 "플레이만(낮은 cap·높은 fill)"에게 **특정 조건에서 진다**를 테스트로 박제(P2 vs P3 접전 계약).
- 최종 = **독립 QA**(§2-2) — 자기검수 금지.
