# LLD — Phase 2 web (에픽 p2-web)

> 스코프: `apps/web/**`. 계약 = openapi(V1) + `docs/plan-v3/api/openapi-v2.yaml`(p2-server W0 산출 — 타입 생성 2스펙 병합). 디자인은 **design 트랙(#76) 아트 디렉션 확정 전엔 현행 톤 유지** — 구조·기능 먼저, 리스킨은 art-direction.md 발행 후 designer 에이전트로(매니저 조율).

## 1. OAuth 목 화면 (AC-A1)
/login 개편: 구글/애플/게스트 3버튼 → mock 동의 모달(구글/애플 스타일 모사 금지 — 제네릭 "OO 계정으로 계속" 목 화면) → 최초면 닉네임 입력 → 로그인. provider 뱃지 표시.

## 2. 전술보드 + 스냅샷 (AC-B, 핵심)
- `deck/TacticsBoard.tsx`: 피치 배경 위 선수 토큰 **드래그앤드롭**(포메이션 슬롯 스냅, 벤치 스트립과 상호 드래그). 라이브러리: `@dnd-kit/core`(터치 지원, 유지 활발) — 신규 의존 1개 승인됨. 폰: 드래그 또는 탭-탭 배치 병행(접근성).
- 선수 토큰 탭 → 시트: **상단 = 전술 지시**(익숙한 UI: 역할 셀렉트, 성향 토글칩 — 지시 카탈로그 기반 프리정의 칩) / **하단 = 프롬프트**(자유 문장, "감독의 한마디" 프레임) — "정형 전술 + 자연어 주문" 2레이어 인지(AC-B4). 칩 선택은 프롬프트 문구로 합성돼 전송(카탈로그와 정합).
- 팀 전술 패널: 라인/압박/템포/폭 슬라이더(수동 전술, P2-D4) + "AI에 맡기기" 토글.
- 팀 파워 바(AC-B5): 선발 합산 + 브리핑에서 상대와 비교 게이지.
- 스냅샷 3슬롯 UI: 저장/로드/이름/복제. 덱 화면 = 편집기+슬롯 관리. 브리핑 = 같은 편집기 임베드(스냅샷 로드 후 전면 수정, AC-B2) — **편집기 컴포넌트 완전 공유**(중복 구현 금지).

## 3. 매치 확장 표시 (AC-C)
- 컨디션 시계 컴포넌트(12시=최고·6시=최저, 바늘+색): 브리핑 라인업·선수 시트에 표시.
- 관계 표시: 선수 시트에 신뢰도 게이지+성격 아이콘, 로비/덱에 팀 사기 위젯.
- 마킹 UI: 상대 분석 테이블에서 상대 선수 탭 → "이 선수 마크" 원탭 칩(프롬프트 자동 합성) — 디테일 지시의 원탭화 예시.

## 4. 트레이드 탭 (AC-D)
/trade: 슬롯 3카드 — WAITING(남은 시간 카운트다운+**포인트로 단축** 버튼·비용 표시), OPEN-FA(대상 선수 카드+제안 빌더: 내 선수 다중선택+포인트 슬라이더+성공확률 실시간 표시), OPEN-TRADE(요구/대가 비교+수락(확률 표시)/거절). 결과 연출(성공/실패). 확률·시간은 전부 서버 응답 값 표시(클라 계산 금지).

## 5. 로그 탭 (AC-E)
/logs: 경기(필터: 모드/시즌, 행 탭→기존 매치 상세·재생 링크) · 트레이드 이력 · 랭킹(리더보드+내 순위+개인 기록 카드).

## 6. 리그 (AC-F)
/league: 시즌 없으면 시작 CTA → 대시보드: 순위표(승점·골득실, 내 팀 하이라이트) / 일정(라운드별, 봇전 결과 포함) / [다음 경기] → 기존 매치 플로우로 진입(리그 뱃지·라운드 표시). 시즌 종료 화면(최종 순위·보상 연출) → 새 시즌 CTA. 로비 개편: 싱글 → 연습/리그 선택.

## 7. 반응형 (AC-G1)
390px 기준 완성 + ≥1024px: 전술보드=보드+사이드패널 2컬럼, 리그=순위표·일정 병렬, 네비게이션=하단탭(모바일)/사이드바(데스크탑). 전 화면 가로 오버플로 0(기존 규율 유지).

## 8. 웨이브
W0 OAuth 화면+타입 병합+네비 개편 → W1 전술보드+스냅샷(핵심, 가장 큼) → W2 컨디션·관계 표시+마킹 원탭 → W3 트레이드 → W4 로그·랭킹 → W5 리그 → W6 반응형 마감+E2E(리그 한 시즌 stub 완주 브라우저 E2E 포함). 각 웨이브 verifier PASS. 시각 판정은 독립 QA/verifier 캡처 확인.
