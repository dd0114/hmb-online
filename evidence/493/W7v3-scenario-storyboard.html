원칙: 각 순간 허용 액션 1개만(나머지 차단) · 전 유저 동일 결과(튜토리얼 고정 덱+고정 시드, AI 호출 0) · 반드시 승리 · 무료 쿠폰 인프라

전체 흐름 한눈에

S0 스타터팩→ S1 게임시작 모달→ S2 덱셋팅 (AUTO→프롬프트→저장) 💰→ S3 경기 (화면 투어→관전, 필승)→ S4 결과 열람 💰→ S5 성장 (강화 무료+승급) 💰→ S6 트레이드 (에픽 확정+단축 무료) 💰→ S7 완주 💰
💰 = 300젬 우편 지급 지점 (덱저장 · 결과열람 · 첫강화 · 첫트레이드 · 완주). 첫 뽑기 300젬은 강제 흐름 밖에서 트리거만 유지(조정 ④).

S0 — 스타터팩 (온보딩 직후)

스타터팩 수령
기존 스타터 구성 (선수팩·재화)
+ 튜토리얼 카드 ×2장
(같은 브론즈 카드 — 승급 재료)
+ 카드 XP 프리필 (즉시 강화 가능)
+ 쿠폰 2장: 강화 무료권 · 트레이드 단축권
  • 신규 유저 스타터팩에 고정 튜토리얼 카드 1종 × 2장 추가 — 전 유저 같은 카드. 2장인 이유 = S5 에서 승급 재료.
  • 그 카드는 경험치가 미리 채워져 있어 S5 에서 바로 강화 가능.
  • 무료 쿠폰 2장 지급 — "첫 강화 무료" · "트레이드 단축 무료". 쿠폰은 일반 인프라(추후 이벤트 재사용 가능)로 설계.
  • 기존 유저에게는 재지급 없음.

S1 — 게임 시작 → 튜토리얼 제안 모달

홈
[게임 시작] 타일 (탭)
"연습경기로 튜토리얼을 진행해볼까요?"
[시작하기] (크게) · [건너뛰기] (작게)
  • 홈에서 [게임 시작] 첫 탭 → 모달. [시작하기]가 기본 강조.
  • 건너뛰기 시: 다시 묻지 않음. 행동 보상 5종(덱저장·결과열람·강화·트레이드·뽑기)은 각 행동 시 여전히 지급, 완주 보상만 못 받음.
  • 수락 → 덱 화면으로 자동 이동, 온레일 시작.

S2 — 덱셋팅 (온레일 · 튜토리얼 고정 덱)

허용 액션 1개씩AUTO → 선수 1명 프롬프트 → 저장

덱 화면 — 스텝 ①
선수 슬롯들 (잠김)
[AUTO] ← 이것만 눌림
[저장] (잠김)
"AUTO 를 누르면 자동으로 베스트 라인업이 배치돼요"
스텝 ② → ③
지정 선수 1명 하이라이트 (탭)
"이 선수에게 한마디 지시를 적어보세요"
→ 프롬프트 입력 (아무 문구 OK)
[저장] ← 입력 후 이것만
💰 "덱 저장 보상 300젬이 우편으로!"
  • 덱은 튜토리얼 고정 덱(보유 선수 아님) — 시드 불변의 핵심.
  • ① AUTO 만 누를 수 있음 → 자동 배치. ② 지정 선수 1명 탭 → 프롬프트 강제 입력(자유 문구, 이번 경기 시뮬에는 미반영 — 유저에게 고지하지 않음, 전 유저 동일 결과 유지). ③ 저장 → 보상 💰.
  • 저장 후: "이제 경기하러 가볼까요?" → 경기로.

S3 — 연습경기 (고정 매치 · 화면 투어 → 관전)

진입 시 재생 정지 · 스킵 잠금화면 요소를 하나씩 확인 → 투어 끝나면 재생

경기 화면 (일시정지 상태)
① 스코어보드 · 시계
② 경기 장면 (피치)
③ 타임라인 · 장면 핀 (골/선방 점프)
④ 재생 컨트롤 · 배속
⑤ 통계 (정보 토글)
⑥ [스킵] 🔒 투어 중 잠김
순서대로 하나씩 하이라이트 →
탭하면 설명 → 다음
  • 매치 = 서버 고정 시드 + 튜토리얼 덱. AI 호출 0 → 대기 0. 전 유저 bit-identical 한 승리 경기(승리 시드를 실제 시뮬로 스캔해 고정).
  • 진입 직후 재생 정지 + 스킵 잠금. 화면 요소 ①~⑥을 한 개씩 눌러보게 하며 설명 — 그동안 경기 진행 안 됨.
  • 투어 완료 → 재생 시작 + 스킵 해제. 이후는 일반 관전과 동일(전·후반, 하프타임, 배속, 스킵 자유).
  • 하프타임: 교체 화면 간단 안내만, 교체 강제 없음 (조정 ⑤).

S5 — 성장 (강화 1회 무료 + 승급 1회, 강제)

선수 탭 진입 시 강제튜토리얼 카드로 강화 → 승급

선수 상세 — 스텝 ①
튜토리얼 카드 (XP 꽉 참)
[강화] 비용: 500G → 무료 쿠폰 적용 0G
"무료 강화권으로 강화해보세요!"
→ 강화 성공 연출
스텝 ②
[승급] 재료: 같은 카드 1장 (보유 ✓)
비용: 골드 (직접 소비 — 골드 써보기)
"카드 2장을 합쳐 성★을 올려보세요!"
→ 승급 성공 연출
💰 "첫 강화 보상 300젬!"
  • 선수 탭 진입 시 튜토리얼 카드 상세로 강제 유도.
  • ① 강화: XP 프리필 + 첫 강화 무료 쿠폰 자동 적용(비용 0 표시) → 강화 경험.
  • ② 승급: 스타터로 받은 같은 카드 2장 → 성★ 승급. 승급 비용은 골드 직접 소비 = "골드 써보기" 경험 (조정 ③).
  • 완료 → 💰 FIRST_ENHANCE 300젬.

#기본안비고
①덱셋팅 순서 = AUTO → 프롬프트 → 저장(마지막)말씀 순서는 "AUTO→저장→프롬프트"였는데, 프롬프트를 저장에 담는 게 자연스러워 저장을 마지막에 둠
②경기 중 "탭 투어" = 경기 화면 요소(스코어보드·타임라인·배속·통계·스킵) 투어앱 하단 탭(홈·덱·선수·영입…) 투어 의미였다면 변경 — 하단 탭은 경기 중 잠기는 구조라 경기 화면 요소로 해석
③강화만 무료(쿠폰), 승급은 골드 소비"골드도 써보게" 경험을 승급 쪽에 배치
④뽑기는 강제 흐름 제외, 첫 뽑기 300젬 트리거만 유지이번 말씀에 뽑기 강제가 없어 제외
⑤하프타임 = 간단 안내만 (교체 강제 없음)교체까지 강제하면 흐름이 길어짐
⑥건너뛴 유저 재진입 경로 없음 (1회 제안)필요하면 내 정보에 "튜토리얼 다시 보기" 추가 가능
